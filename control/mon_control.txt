#
# Format:  <monster>  <attack>  <teleport>  <skill>  <level>
#
# <attack>
#   -1  ignore even if this mob attacks us
#    0  leave alone unless it attacks us first (defensive)
#    1  always auto-attack this mob on sight
#
# <teleport>
#    0  never wing because of this mob
#    1  wing when this mob attacks us (fires on 0x0B, before HP drops)
#    2  wing when this mob is within teleportSightRange tiles
#
# <skill>   skill id to cast on this mob   (RayRag: 11 = Fire Bolt, 12 = Cold Bolt)
#           0 = basic melee attack (0x0B) — for Swordsman / Merchant / etc.
# <level>   skill level to cast            (ignored when skill=0)
#
# Multi-word names supported: everything before the last 4 numbers is the name.
# 'all' sets the default for mobs not listed below.
# Case-insensitive. Lines starting with # are comments.
# ================================================================
